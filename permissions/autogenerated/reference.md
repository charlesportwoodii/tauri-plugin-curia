## Default Permission

Allows the webview to emit log records.

#### This default permission set includes the following:

- `allow-log`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`curia:allow-log`

</td>
<td>

Enables the log command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`curia:deny-log`

</td>
<td>

</td>
</tr>
</table>
